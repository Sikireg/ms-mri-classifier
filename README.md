# MS-MRI-Assistant

Нейросетевая система поддержки врачебных решений для детекции 
рассеянного склероза (РС) на МРТ-снимках головного мозга.

## О проекте

Индивидуальная работа по дисциплине «Архитектура компьютера».

Модель не просто классифицирует снимок как «MS» или «Normal», но и:
- Визуализирует области внимания нейросети (Grad-CAM)
- Выделяет патологические зоны рамками (bounding boxes)
- Оценивает объём поражения белого вещества
- Формирует дифференциальный ряд с рекомендациями по дообследованию

 **Внимание:** проект носит исследовательский характер и не предназначен 
для клинического применения. Окончательный диагноз ставит врач.

---

## Модель

**Архитектура:** ResNet18 (18 слоёв, остаточные связи)

**Подход:** Transfer Learning — веса предобучены на ImageNet (1.2 млн изображений), 
затем дообучены на МРТ-снимках.

**Изменения в архитектуре:**
- Последний полносвязный слой (1000 классов ImageNet) заменён на блок:
  - `Dropout(p=0.3)` — регуляризация
  - `Linear(512, 2)` — 2 выхода: MS / Normal

**Вход:** 224×224 пикселей, RGB, нормализация статистиками ImageNet.

**Функция потерь:** CrossEntropyLoss с весами классов (компенсация дисбаланса MS:Normal ≈ 1:3).

**Оптимизатор:** Adam, lr=5×10⁻⁴, weight_decay=1×10⁻⁴.

## Датасет

### Источники

| Источник | MS | Normal | Ссылка |
|----------|-----|--------|--------|
| Burak Tasci (Kaggle) | 650 (axial) + 761 (sagittal) | 1002 (axial) + 1014 (sagittal) | [kaggle.com/datasets/buraktaci/multiple-sclerosis](https://www.kaggle.com/datasets/buraktaci/multiple-sclerosis) |
| omarradi1993 (Kaggle) | 1405 | 6904 | [kaggle.com/datasets/omarradi1993/mri-scans-brain-neurological-classes](https://www.kaggle.com/datasets/omarradi1993/mri-scans-brain-neurological-classes) |

### Как разложить датасеты

После скачивания архивов структура должна быть такой:

```
neuralNet/
├── dataset/
│   ├── MS/                                    ← из Burak Tasci
│   │   ├── Control Axial_crop/                (1002 файла)
│   │   ├── Control Saggital_crop/             (1014 файлов)
│   │   ├── MS Axial_crop/                     (650 файлов)
│   │   └── MS Saggital_crop/                  (761 файл)
│   │
│   └── mri_scans/                             ← из omarradi1993
│       ├── MS/                                (1405 файлов)
│       └── Normal/                            (6904 файла)
│
├── prepare_dataset.py
├── train.py
├── test.py
└── gradcam.py
```

**Важно:** папки внутри `dataset/MS/` должны называться именно так 
(с заглавными буквами и пробелами), как в оригинальном архиве.

### Как делится датасет

Скрипт `prepare_dataset.py` выполняет следующие шаги:

**Шаг 1. Копирование аксиальных срезов в общий пул**

| Класс | Откуда берётся | Файлов |
|-------|---------------|--------|
| MS | `MS/MS Axial_crop/` + `mri_scans/MS/` | 650 + 1405 = 2055 |
| Normal | `MS/Control Axial_crop/` + `mri_scans/Normal/` | 1002 + 6904 = 7906 |

Сагиттальные срезы на этом этапе **не трогаются**.

**Шаг 2. Разбивка 80/10/10 через splitfolders**

| Выборка | MS | Normal | Всего |
|---------|-----|--------|-------|
| Train | 1644 | 6324 | 7968 |
| Val | 205 | 790 | 995 |
| Test | 205 | 790 | 995 |

Разбивка с фиксированным `seed=42` — воспроизводима при повторном запуске.

**Шаг 3. Добавление сагиттальных срезов в тест**

Сагиттальные проекции (не представленные при обучении) добавляются 
**только в тестовую выборку** для оценки кросс-проекционного обобщения:

| Выборка | MS | Normal | Всего |
|---------|-----|--------|-------|
| Train | 1644 | 6324 | 7968 |
| Val | 205 | 790 | 995 |
| **Test** | **966** | **1804** | **2770** |

Все сагиттальные файлы получают префикс `sag_` в имени, чтобы их можно было 
отличить при анализе.

### Итоговая структура после prepare_dataset.py

```
dataset/processed/
├── train/
│   ├── MS/
│   └── Normal/
├── val/
│   ├── MS/
│   └── Normal/
└── test/
    ├── MS/              (включая sag_*)
    └── Normal/          (включая sag_*)
```

## Установка и запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/<твой-username>/MS-MRI-Assistant.git
cd MS-MRI-Assistant
```

### 2. Создать виртуальное окружение

```bash
python -m venv venv

# Windows
venv\Scripts\activate

# Linux/Mac
source venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

Для GPU (CUDA 12.1):
```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

### 4. Скачать датасеты

Скачай архивы с Kaggle (ссылки выше) и разложи согласно структуре.

### 5. Запустить пайплайн

```bash
python prepare_dataset.py    # сборка датасета (~5 минут)
python train.py              # обучение (~15 минут на GPU)
python test.py               # тестирование и метрики
python gradcam.py            # визуализация + отчёты
```

## Результаты

| Метрика | Значение |
|---------|----------|
| Accuracy | 91.60% |
| MS Recall | 95.09% |
| MS Precision | 85.33% |
| MS F1-score | 0.8995 |
| Normal Recall | 89.31% |
| Порог классификации | 0.90 |
| Тестовых снимков | 2987 |

**Почему порог 0.90, а не 0.5:** медицинский приоритет — не пропустить РС. 
При пороге 0.90 модель находит 95% случаев РС, ценой небольшого роста 
ложных тревог (Precision 85%). Это приемлемо для скрининга: ложная тревога 
приводит лишь к дополнительному обследованию, пропуск диагноза — к прогрессии болезни.
