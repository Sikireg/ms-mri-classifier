# MS-MRI-Assistant

Нейросетевая система поддержки врачебных решений для детекции рассеянного склероза (РС) на МРТ-снимках головного мозга.

>  **Внимание:** Проект носит исключительно исследовательский и учебный характер. Он не предназначен для клинического применения. Окончательный диагноз ставит только квалифицированный врач.

---

##  О проекте

Индивидуальная работа по дисциплине «Архитектура компьютера». 

Модель не просто классифицирует снимок как «MS» (рассеянный склероз) или «Normal» (норма), но и предоставляет расширенную аналитику:
-  Визуализирует области внимания нейросети (Grad-CAM).
-  Выделяет патологические зоны рамками (bounding boxes).
-  Оценивает объём поражения белого вещества.
-  Формирует дифференциальный ряд с рекомендациями по дообследованию.

---

##  Модель

- **Архитектура:** ResNet18 (18 слоёв с остаточными связями).
- **Подход:** Transfer Learning. Веса предобучены на ImageNet (1.2 млн изображений), затем дообучены на медицинских МРТ-снимках.
- **Входные данные:** 224×224 пикселей, RGB, нормализация статистиками ImageNet.

### Изменения в архитектуре
Последний полносвязный слой (1000 классов ImageNet) заменён на классификационный блок:
1. `Dropout(p=0.3)` — для регуляризации и борьбы с переобучением.
2. `Linear(512, 2)` — 2 выходных нейрона (MS / Normal).

### Гиперпараметры обучения
| Параметр | Значение |
|----------|----------|
| **Функция потерь** | CrossEntropyLoss с весами классов (компенсация дисбаланса MS:Normal ≈ 1:3) |
| **Оптимизатор** | Adam |
| **Learning Rate** | 5 × 10⁻⁴ |
| **Weight Decay** | 1 × 10⁻⁴ |

После скачивания архивов распакуйте их так, чтобы структура проекта выглядела следующим образом:


>  **Важно:** Папки внутри `dataset/MS/` должны называться именно так (с заглавными буквами и пробелами), как в оригинальном архиве, чтобы скрипт их корректно нашел.

### Логика разбивки датасета (`prepare_dataset.py`)

**Шаг 1. Формирование общего пула аксиальных срезов**
- **MS:** `MS Axial_crop` (650) + `mri_scans/MS` (1405) = **2055 файлов**
- **Normal:** `Control Axial_crop` (1002) + `mri_scans/Normal` (6904) = **7906 файлов**
*(Сагиттальные срезы на этом этапе не используются).*

**Шаг 2. Разбивка 80/10/10 (через `splitfolders`, seed=42)**
| Выборка | MS | Normal | Всего |
|---------|----|--------|-------|
| Train   | 1644 | 6324 | 7968 |
| Val     | 205  | 790  | 995  |
| Test    | 205  | 790  | 995  |

**Шаг 3. Добавление сагиттальных срезов в тест**
Сагиттальные проекции добавляются **только в тестовую выборку** для оценки способности модели к кросс-проекционному обобщению. Все такие файлы получают префикс `sag_` в имени.

| Выборка | MS | Normal | Всего |
|---------|----|--------|-------|
| Train   | 1644 | 6324 | 7968 |

##  Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/<твой-username>/MS-MRI-Assistant.git
cd MS-MRI-Assistant
```

### 2. Создание виртуального окружения
```bash
python -m venv venv

# Для Windows:
venv\Scripts\activate

# Для Linux / macOS:
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```
*(Опционально) Для ускорения обучения на GPU (CUDA 12.1):*
```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

### 4. Запуск пайплайна
Убедитесь, что датасеты разложены правильно (см. раздел выше), и выполните команды по очереди:
```bash
python prepare_dataset.py    # Сборка и разбивка датасета (~5 минут)
python train.py              # Обучение модели (~15 минут на GPU)
python test.py               # Тестирование и вывод метрик
python gradcam.py            # Генерация тепловых карт и отчетов
```

## 📈 Результаты

| Метрика | Значение |
|---------|----------|
| **Accuracy** | 91.60% |
| **MS Recall** | 95.09% |
| **MS Precision** | 85.33% |
| **MS F1-score** | 0.8995 |
| **Normal Recall** | 89.31% |
| **Порог классификации** | 0.90 |
| **Всего тестовых снимков** | 2987 |

>  **Почему порог классификации 0.90, а не 0.5?**  
> В медицине приоритет отдается принципу «не пропустить болезнь». При пороге 0.90 модель находит 95% случаев РС, ценой небольшого роста ложных срабатываний (Precision 85%). Это допустимо для скрининга: ложная тревога ведет лишь к дополнительному обследованию, а пропуск диагноза — к прогрессии заболевания.

## 🛠️ Стек технологий

- **PyTorch** — фреймворк для обучения и инференса.
- **torchvision** — архитектура ResNet18, трансформации изображений, `ImageFolder`.
- **pytorch-grad-cam** — генерация тепловых карт активации.
- **OpenCV** — отрисовка bounding boxes и аннотаций на снимках.
- **scikit-learn** — расчет метрик и весов классов.
- **matplotlib / seaborn** — визуализация графиков и матриц ошибок.
- **splitfolders** — надежная разбивка датасета по папкам.
